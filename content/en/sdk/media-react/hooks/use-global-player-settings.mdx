---
title: "useGlobalPlayerSettings"
description: "Coordinate shared playback and preference changes across multiple mounted Video instances."
---

import {Callout} from "fumadocs-ui/components/callout";

`useGlobalPlayerSettings()` is the advanced page-level hook for shared controls.

<Callout type="info">
  This hook changes shared preferences across mounted videos and does not require a `VideoPlayer` provider. Use player-scoped hooks when a
  control should affect only one video.
</Callout>

## Signature

```tsx
const settings = useGlobalPlayerSettings();
```

It returns shared values and fan-out actions for mounted players, including:

- `muted`
- `volume`
- `playbackRate`
- `preferredQuality`
- `preferredAudioLanguage`
- `preferredSubtitleLanguage`
- `setMuted(muted)`
- `setVolume(volume)`
- `setPlaybackRate(rate)`
- `setPreferredQuality(quality)`
- `setPreferredAudioLanguage(language)`
- `setPreferredSubtitleLanguage(language)`
- `pauseAll()`

## Example

```tsx
import {Video, useGlobalPlayerSettings} from "@rixl/media-react";

function PageLevelPlayerControls() {
  const {muted, setMuted, pauseAll} = useGlobalPlayerSettings();

  return (
    <div className="space-y-4">
      <div className="flex items-center gap-3">
        <button type="button" onClick={() => setMuted(!muted)}>
          {muted ? "Unmute all" : "Mute all"}
        </button>

        <button type="button" onClick={() => pauseAll()}>
          Pause all
        </button>
      </div>
    </div>
  );
}

function App() {
  return (
    <>
      <PageLevelPlayerControls />
      <Video id="FIRST_VIDEO_ID" style={{display: "block", aspectRatio: "16 / 9"}} />
      <Video id="SECOND_VIDEO_ID" style={{display: "block", aspectRatio: "16 / 9"}} />
    </>
  );
}
```

## Notes

- This hook is for page-level coordination, not a replacement for player-scoped hooks.
- Shared language preferences only apply when a mounted player exposes matching tracks.
- For single-player custom UI, prefer the player-scoped hooks in this section.
