title: "Feed props reference"
description: "Configure the Rixl React feed viewport, looping, automatic advancement, mute state, and callbacks."
---

```ts
import type {FeedProps} from "@rixl/media-react/feed";

export const feedProps = {feedId: "YOUR_FEED_ID", muted: true} satisfies FeedProps;
```

## Configuration

| Prop                 | Type                  | Default  | Purpose                                    |
| -------------------- | --------------------- | -------- | ------------------------------------------ |
| `feedId`             | `string`              | `""`     | Rixl feed to load                          |
| `muted`              | `boolean`             | `true`   | Initial feed mute preference               |
| `loop`               | `boolean`             | `false`  | Loop behavior                              |
| `autoscroll`         | `boolean`             | `false`  | Advance on video completion or image dwell |
| `lang`               | `PlayerLanguage`      | `"en"`   | Player language                            |
| `feedFont`           | `FontFamilyKey`       | —        | Feed font configuration                    |
| `analytics`          | `boolean`             | `true`   | Enable analytics                           |
| `analyticsPage`      | `Page`                | `"feed"` | View context                               |
| `safeAreaTabBar`     | `number`              | `12`     | Safe-area value used by feed layout        |
| `className`, `style` | React host attributes | —        | Feed dimensions and layout                 |

Give the feed an explicit height. Published components fetch and paginate by `feedId`; `posts`, `onFetchMore`, and `initialIndex` are not production alternatives for selecting feed data or its starting post.

## Events

| Callback               | Argument                                       |
| ---------------------- | ---------------------------------------------- |
| `onMuteChange`         | Muted boolean                                  |
| `onCurrentIndexChange` | `(index: number, postId: string \| undefined)` |
| `onRixlAnalytics`      | Custom event; payload at `event.detail.event`  |

Refs receive the underlying `RixlFeed` element. See [Feed usage](/en/sdk/media-react/feed-component/basic-usage) for a complete example.
