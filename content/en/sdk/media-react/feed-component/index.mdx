---
title: "React media feed"
description: "Render vertical Rixl image and video feeds in React with SDK pagination, looping, and automatic advancement."
---

`Feed` displays a vertical stream of Rixl image and video posts and loads content through the SDK using `feedId`.

```tsx
import {Feed} from "@rixl/media-react/feed";

export function FeedPage() {
  return <Feed feedId="YOUR_FEED_ID" muted style={{display: "block", height: "36rem"}} />;
}
```

Connect the SDK before mounting the feed and give its host an explicit height.

## Capabilities

- SDK-backed feed loading and pagination.
- Active media coordination while scrolling.
- Looping and automatic advancement options.
- Shared language, font, mute, and analytics configuration.
- Mute and current-index callbacks.

The feed manages its child media components and supplies their feed and post context. Published components do not use direct posts or custom pagination callbacks as a replacement for SDK loading.
