# Hover Preview Player

A video player that plays on mouse hover and pauses when the mouse leaves. Ideal for video thumbnails and preview cards (Netflix/YouTube style).

<Callout type="warning">
  The React `Video` wrapper currently uses the browser's native `<video>` controls and does not include a built-in "hover theme". The examples below show how to build hover behavior yourself with `onMouseEnter` / `onMouseLeave`.
</Callout>

## Live Example

Hover over the video to start playback:

<div className="w-full max-w-md">
  <Video id="your-video-id" className="w-full aspect-video rounded-lg" muted={true} autoPlay={false} />
</div>

## Basic Implementation

```tsx
import {useRef} from "react";
import {Video} from "@rixl/media-react";

function HoverPreview({videoId}: {videoId: string}) {
  const videoRef = useRef<HTMLVideoElement>(null);

  return (
    <div
      className="w-full aspect-video rounded-lg overflow-hidden"
      onMouseEnter={() => videoRef.current?.play()}
      onMouseLeave={() => videoRef.current?.pause()}
    >
      <Video id={videoId} className="w-full h-full object-cover" muted={true} autoPlay={false} />
    </div>
  );
}
```

## How It Works

- Video is **paused by default** with `autoPlay={false}`
- Playback starts on `onMouseEnter` and pauses on `onMouseLeave`
- Keep `muted={true}` so autoplay restrictions do not block playback

## Use Cases

### Video Thumbnail Grid

```tsx
import {useRef} from "react";
import {Video} from "@rixl/media-react";

function VideoGrid({videos}) {
  return (
    <div className="grid grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-4">
      {videos.map((video) => (
        <HoverPreview key={video.id} videoId={video.id} />
      ))}
    </div>
  );
}

function HoverPreview({videoId}: {videoId: string}) {
  const videoRef = useRef<HTMLVideoElement>(null);

  return (
    <div
      className="w-full aspect-video rounded-lg overflow-hidden"
      onMouseEnter={() => videoRef.current?.play()}
      onMouseLeave={() => videoRef.current?.pause()}
    >
      <Video id={videoId} className="w-full h-full object-cover" muted={true} autoPlay={false} />
    </div>
  );
}
```

### Content Card with Hover Preview

```tsx
function ContentCard({videoId, title, description}) {
  return (
    <div className="rounded-xl overflow-hidden shadow-lg">
      <HoverPreview videoId={videoId} />
      <div className="p-4">
        <h3 className="font-bold text-lg">{title}</h3>
        <p className="text-gray-600 text-sm">{description}</p>
      </div>
    </div>
  );
}
```

## When to Use

**Use hover previews for:**

- Video thumbnail grids and galleries
- Content cards with video previews
- Product showcases
- Portfolio displays

Need full controls? Use the [Standard Player](/en/sdk/examples/standard-player) instead.
