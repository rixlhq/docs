---
title: "TypeScript types"
description: "Use the shipped Rixl Core and framework types for media metadata, uploads, player state, and component props."
---

The SDK ships TypeScript declarations. Import types from the package rather than copying interfaces into application code; the declarations track the implementation and SDK schema.

## Core types

```ts
import type {
  ImageData,
  VideoData,
  FeedPost,
  FeedPostsResponse,
  PlayerState,
  SettingsState,
  AnalyticsEvent,
  ConnectConfig,
  CreateImageUploadOptions,
  CreateVideoUploadOptions,
} from "@rixl/media-core";
```

| Type                                       | Purpose                                        |
| ------------------------------------------ | ---------------------------------------------- |
| `ImageData`, `VideoData`                   | Media metadata and file references             |
| `FeedPost`, `FeedPostsResponse`            | Feed content and paginated results             |
| `PlayerState`, `SettingsState`             | Player state and shared preferences            |
| `AnalyticsEvent`                           | Analytics event union                          |
| `ConnectConfig`, `AuthConfig`              | Shared client connection configuration         |
| `Chapter`, `SubtitleTrack`, `QualityLevel` | Video navigation, captions, and quality        |
| `ProgressBarProps`, `ProgressBarControls`  | Browser progress interactions                  |
| Upload option and result types             | Presigned upload creation and transfer results |

Framework packages re-export these types through `/core`.

## Component props

UI props belong to their framework package:

```ts
import type {ImageProps} from "@rixl/media-react/image";
import type {VideoProps} from "@rixl/media-react/video";
import type {FeedProps} from "@rixl/media-react/feed";
```

Vue, Svelte, and Astro also export their own prop types. Angular components expose typed inputs and outputs. Lit registers tag-name types, so `document.createElement("rixl-video")` is typed after importing `/video`.

## Validate configuration

```ts
import type {VideoProps} from "@rixl/media-react/video";

export const video = {
  id: "YOUR_VIDEO_ID",
  muted: true,
  chapters: false,
} satisfies VideoProps;
```

See [Core API](/en/sdk/media-core/core-api), [uploads](/en/sdk/media-core/upload), and the framework's component reference for usage.
