RIXL provides idiomatic Angular standalone components via `@rixl/media-angular`, backed by the shared Lit UI. The package is self-contained — the core ships bundled inside, so you only install the one package. Compatible with Angular 20+.

## Installation

```bash
npm install @rixl/media-angular
```

## Authentication

Initialize the RIXL client in an `APP_INITIALIZER` or within your root application config:

```ts title="app.config.ts"
import {ApplicationConfig} from "@angular/core";
import {connect} from "@rixl/media-angular/core";

export const appConfig: ApplicationConfig = {
  providers: [
    {
      provide: "RIXL_INIT",
      useFactory: () => () =>
        connect({
          baseUrl: "https://api.rixl.com",
          apiKey: "your-api-key",
        }),
    },
  ],
};
```

`connect` initializes the shared HTTP client and seeds the analytics context (`device`, `session`, `navigator`, and user locale).

## Video Player

Import `VideoComponent` into your standalone component and bind inputs directly — no `CUSTOM_ELEMENTS_SCHEMA` needed:

```ts title="video-player.component.ts"
import {Component, Input} from "@angular/core";
import {VideoComponent} from "@rixl/media-angular";

@Component({
  selector: "app-video-player",
  standalone: true,
  imports: [VideoComponent],
  template: `
    <div class="video-container">
      <rixl-media-video [id]="videoId" [controls]="controls" (play)="onPlay()"></rixl-media-video>
    </div>
  `,
})
export class VideoPlayerComponent {
  @Input() videoId!: string;
  @Input() controls = true;

  onPlay() {
    console.log("Playback started");
  }
}
```

The video component provides adaptive playback with the built-in control bar. Chapter markers are toggled with the `chapters` boolean — chapter data itself comes from `videoData.chapters`. Player outputs include `play`, `pause`, `pausedChange`, `ended`, `timeUpdate`, `loadedMetadata`, `error`, `volumeChange`, `loadingChange`, `rateChange`, and `qualityChange`.

## Responsive Images

Render responsive images optimized with AVIF and WebP delivery:

```ts title="image-viewer.component.ts"
import {Component, Input} from "@angular/core";
import {ImageComponent} from "@rixl/media-angular";

@Component({
  selector: "app-image-viewer",
  standalone: true,
  imports: [ImageComponent],
  template: `<rixl-media-image [id]="imageId" [alt]="alt"></rixl-media-image>`,
})
export class ImageViewerComponent {
  @Input() imageId!: string;
  @Input() alt = "Media image";
}
```

## Media Feeds

Render story carousels and infinite vertical feeds:

```ts title="feed.component.ts"
import {Component, Input} from "@angular/core";
import {FeedComponent} from "@rixl/media-angular";

@Component({
  selector: "app-media-feed",
  standalone: true,
  imports: [FeedComponent],
  template: `<rixl-media-feed [feedId]="feedId" [loop]="true" [autoscroll]="true"></rixl-media-feed>`,
})
export class MediaFeedComponent {
  @Input() feedId!: string;
}
```

## Analytics

Set `analyticsPage` to `"feed"`, `"standalone"`, or `"profile"` to tag the view context. The underlying player dispatches a bubbling, composed `rixl-analytics` custom event carrying an `AnalyticsEvent` payload — listen for it at the document level to inspect or forward analytics:

```ts
document.addEventListener("rixl-analytics", (e) => {
  console.log((e as CustomEvent).detail.event);
});
```

For details on the event taxonomy and core helpers, see [Analytics Integration](/en/sdk/media-react/video-component/analytics-integration) and [Core API](/en/sdk/media-core/core-api).
