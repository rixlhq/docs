RIXL provides idiomatic Vue 3 components via `@rixl/media-vue`, backed by the shared Lit UI. The package is self-contained — the core ships bundled inside, so you only install the one package. Use `<Video>`, `<Image>`, and `<Feed>` directly in any Vue or Nuxt application with standard reactive props and event listeners.

## Installation

```bash
npm install @rixl/media-vue
```

Requires Vue 3.3 or higher.

## Authentication

Initialize the RIXL client once in your application root or entry file before rendering media components:

```ts
import {connect} from "@rixl/media-vue/core";

await connect({
  baseUrl: "https://api.rixl.com",
  apiKey: "your-api-key",
});
```

`connect` initializes the shared HTTP client and seeds the analytics context (`device`, `session`, `navigator`, and user locale).

## Video Player

Import the `Video` component and bind your video ID dynamically:

```vue title="VideoPlayer.vue"
<script setup lang="ts">
import {Video} from "@rixl/media-vue";

defineProps<{
  videoId: string;
}>();
</script>

<template>
  <div class="video-container">
    <Video :id="videoId" autoplay controls />
  </div>
</template>
```

The `Video` component provides adaptive playback with the built-in control bar. Set `controls` to enable it, or use `theme="hideUI"` and render your own controls alongside it. Chapter markers are toggled with the `chapters` boolean — chapter data itself comes from `videoData.chapters`.

## Responsive Images

Render optimized, responsive images with automatic WebP/AVIF format negotiation:

```vue title="ImageViewer.vue"
<script setup lang="ts">
import {Image} from "@rixl/media-vue";

defineProps<{
  imageId: string;
}>();
</script>

<template>
  <Image :id="imageId" alt="Media asset" />
</template>
```

## Media Feeds

Display infinite-scroll feeds or story carousels using the `Feed` component:

```vue title="MediaFeed.vue"
<script setup lang="ts">
import {Feed} from "@rixl/media-vue";

defineProps<{
  feedId: string;
}>();
</script>

<template>
  <Feed :feed-id="feedId" loop autoscroll />
</template>
```

## Events & Analytics

The media components emit player events you can listen to with Vue's `@` syntax:

```vue title="AnalyticsExample.vue"
<script setup lang="ts">
import {Video} from "@rixl/media-vue";

function handlePlay(event: Event) {
  console.log("Playback started:", event);
}
</script>

<template>
  <Video id="vid_123" analytics-page="standalone" @play="handlePlay" />
</template>
```

Available emits include `play`, `pause`, `paused-change`, `ended`, `time-update`, `loaded-metadata`, `error`, `volume-change`, `loading-change`, `rate-change`, and `quality-change`. Set `analytics-page` to `"feed"`, `"standalone"`, or `"profile"` to tag the view context.

The underlying player also dispatches a bubbling, composed `rixl-analytics` custom event carrying an `AnalyticsEvent` payload. Listen for it at the document level to inspect or forward analytics:

```ts
document.addEventListener("rixl-analytics", (e) => {
  console.log((e as CustomEvent).detail.event);
});
```

For details on the event taxonomy and core helpers, see [Analytics Integration](/en/sdk/media-react/video-component/analytics-integration) and [Core API](/en/sdk/media-core/core-api).
