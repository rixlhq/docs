## Importing the Feed Component

```tsx
import {Feed} from "@rixl/media-react";
```

## Essential Props

Every Feed component needs at minimum:

```tsx
<Feed
  feedId="your-feed-id" // Required: Your feed ID from dash.rixl.com/feeds
/>
```

## Simple Feed Example

```tsx
import {Feed} from "@rixl/media-react";

function FeedExample() {
  return <Feed feedId="your-feed-id" limit={10} buffer={3} analyticsPage="feed" />;
}
```

## Analytics Events

Listen to all feed and child post analytics events with one handler:

```tsx
import {Feed} from "@rixl/media-react";

function FeedWithAnalytics() {
  return (
    <Feed
      feedId="your-feed-id"
      analyticsPage="feed"
      onRixlAnalytics={(e) => {
        const {event} = e.detail;
        console.log(event._type, event);
      }}
    />
  );
}
```

## Lit / Vanilla HTML

```html
<script type="module">
  import "@rixl/media-lit/feed";

  const feed = document.querySelector("rixl-feed");
  feed.addEventListener("rixl-analytics", (e) => {
    console.log(e.detail.event);
  });
</script>

<rixl-feed feed-id="your-feed-id" analytics-page="feed"></rixl-feed>
```

## Autoscroll and Loop

```tsx
<Feed feedId="your-feed-id" autoscroll={true} loop={true} />
```

## Pagination Tuning

```tsx
<Feed feedId="your-feed-id" limit={20} buffer={5} />
```

- `limit` — number of posts fetched per page
- `buffer` — how many posts outside the viewport are kept in the DOM

## Best Practices

<Callout type="default">
  **Feed ID**: The `feedId` is automatically passed to every child image and video post so analytics can be attributed correctly.
</Callout>

<Callout type="info">
  **Buffer size**: A higher `buffer` improves scroll smoothness but uses more memory. A lower `buffer` is better for long feeds on low-end
  devices.
</Callout>

<Callout type="warning">
  **Legacy props**: `lang`, `feedFont`, `creatorId`, and `startPostId` are accepted for backward compatibility but are not forwarded to the
  Lit element.
</Callout>
