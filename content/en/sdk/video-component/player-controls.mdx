<Callout type="info">
  The React `Video` component is a `@lit/react` wrapper around the Lit `<rixl-video>` element. It renders a standard HTML `<video>` element and therefore uses the browser's native controls when `controls` is set. Custom control bars can be built around the scope-based `VideoPlayer` and hooks API documented in [Hooks](/en/sdk/hooks), or by listening to `onRixlAnalytics`.
</Callout>

## Standard Video Attributes

Because `<rixl-video>` and the React `Video` wrapper expose the underlying HTML `<video>` element, you can use all standard media attributes:

| Attribute     | Type                             | Description                                                                           |
| ------------- | -------------------------------- | ------------------------------------------------------------------------------------- |
| `controls`    | `boolean`                        | Show the browser's default control bar (play, pause, seek, volume, fullscreen, etc.). |
| `autoPlay`    | `boolean`                        | Start playback as soon as the video can play.                                         |
| `muted`       | `boolean`                        | Mute audio by default.                                                                |
| `loop`        | `boolean`                        | Loop playback when the video ends.                                                    |
| `playsInline` | `boolean`                        | Prefer inline playback on mobile browsers.                                            |
| `poster`      | `string`                         | URL of an image to show before the video loads.                                       |
| `preload`     | `"none" \| "metadata" \| "auto"` | Hints how much of the video to preload.                                               |

```tsx
import {Video} from "@rixl/media-react";

<Video id="your-video-id" className="w-full h-auto rounded-lg" controls autoPlay={false} muted loop />;
```

## Native Control Bar

When `controls` is enabled, the browser renders its own control bar. The exact appearance and capabilities depend on the browser, but typically include:

- **Play / Pause**
- **Seek bar**
- **Volume control**
- **Mute / Unmute**
- **Fullscreen**
- **Picture-in-Picture** (in supported browsers)

<Callout type="info">
  Features such as playback speed presets, subtitle styling, multiple audio tracks, and chapter markers are handled by the browser if the underlying `<video>` element supports them. The Rixl `Video` component does not currently add a custom settings menu on top of the native controls.
</Callout>

## Analytics Events

The video component emits `rixl-analytics` events through `onRixlAnalytics`. These events describe how users interact with the player:

| Event                  | Type            | Description                                               |
| ---------------------- | --------------- | --------------------------------------------------------- |
| `content_view` `start` | `content_views` | The video entered the viewport and started being tracked. |
| `content_view` `watch` | `content_views` | Periodic view heartbeat while the video is visible.       |
| `content_view` `end`   | `content_views` | The video left the viewport or was unmounted.             |
| `play`                 | `interaction`   | The user started playback.                                |
| `pause`                | `interaction`   | The user paused playback.                                 |
| `seek`                 | `interaction`   | The user seeked to a new position.                        |
| `mute` / `unmute`      | `interaction`   | Audio was muted or unmuted.                               |
| `volume_change`        | `interaction`   | The volume level changed.                                 |
| `fullscreen`           | `interaction`   | Fullscreen mode was entered or exited.                    |
| `picture_in_picture`   | `interaction`   | Picture-in-Picture mode was entered or exited.            |
| `quality_change`       | `interaction`   | The HLS quality level changed.                            |
| `settings_open`        | `interaction`   | The native settings menu was opened.                      |
| `error`                | `error`         | A media load or playback error occurred.                  |

```tsx
import {Video} from "@rixl/media-react";

<Video
  id="your-video-id"
  controls
  analytics
  analyticsPage="video"
  onRixlAnalytics={(e) => {
    console.log("Rixl analytics event:", e.detail.event);
  }}
/>;
```

## Custom Control Bars

If you need a fully custom control bar, you have two recommended paths:

1. **Scope-based hooks** — Use `<VideoPlayer>` with `usePlayback`, `usePlayerProgress`, and `useMediaSettings`. This is the legacy React player API and is documented in [Hooks](/en/sdk/hooks).
2. **Siblings + `onRixlAnalytics`** — Place your own controls as siblings of `<Video>` and drive them from the analytics events, your own React state, or a wrapped native `<video>` element.

<Callout type="warning">
  Do not render custom controls as children of the `Video` component. The `Video` wrapper is a self-contained Lit web component and does not
  provide an internal player scope for child controls.
</Callout>

## Keyboard Shortcuts

When the video element has focus, browsers generally support the following shortcuts on the native `<video>` control bar:

| Action                    | Shortcut                |
| ------------------------- | ----------------------- |
| Play / Pause              | `Space` or `K`          |
| Seek forward 5 s          | `→`                     |
| Seek backward 5 s         | `←`                     |
| Volume up                 | `↑`                     |
| Volume down               | `↓`                     |
| Mute / Unmute             | `M`                     |
| Toggle fullscreen         | `F`                     |
| Toggle Picture-in-Picture | `I` (browser dependent) |

## Picture-in-Picture and Fullscreen

Picture-in-Picture and fullscreen are triggered from the browser's native control bar or by calling the standard `<video>` element APIs on a ref:

```tsx
import {useRef} from "react";
import {Video} from "@rixl/media-react";

function Player({videoId}) {
  const ref = useRef(null);

  return (
    <>
      <Video ref={ref} id={videoId} controls className="w-full h-auto" />
      <button onClick={() => ref.current?.requestFullscreen?.()}>Fullscreen</button>
    </>
  );
}
```

<Callout type="info">
  Not all browsers support Picture-in-Picture. The `Video` component will emit a `picture_in_picture` analytics interaction event when the
  browser fires the corresponding `enterpictureinpicture` / `leavepictureinpicture` events.
</Callout>
