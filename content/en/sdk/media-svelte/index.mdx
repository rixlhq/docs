RIXL provides idiomatic Svelte 5 components via `@rixl/media-svelte`, backed by the shared Lit UI. The package is self-contained — the core ships bundled inside, so you only install the one package. Render `<Video>`, `<Image>`, and `<Feed>` as standard Svelte components with reactive props.

## Installation

```bash
npm install @rixl/media-svelte
```

Requires Svelte 5 or higher.

## Authentication

Connect to RIXL in your root layout or on application mount:

```ts
import {onMount} from "svelte";
import {connect} from "@rixl/media-svelte/core";

onMount(async () => {
  await connect({
    baseUrl: "https://api.rixl.com",
    apiKey: "your-api-key",
  });
});
```

`connect` initializes the shared HTTP client and seeds the analytics context (`device`, `session`, `navigator`, and user locale).

## Video Player

Import the `Video` component in your Svelte component:

```svelte title="VideoPlayer.svelte"
<script lang="ts">
  import {Video} from "@rixl/media-svelte";

  interface Props {
    videoId: string;
    autoplay?: boolean;
    controls?: boolean;
  }

  let { videoId, autoplay = false, controls = true }: Props = $props();
</script>

<div class="player-wrapper">
  <Video id={videoId} {autoplay} {controls} />
</div>
```

The `Video` component provides adaptive playback with the built-in control bar. Chapter markers are toggled with the `chapters` boolean — chapter data itself comes from `videoData.chapters`.

## Responsive Images

Render responsive images with automatic format optimization and lazy loading:

```svelte title="ImageViewer.svelte"
<script lang="ts">
  import {Image} from "@rixl/media-svelte";

  interface Props {
    imageId: string;
    alt?: string;
  }

  let { imageId, alt = "Media item" }: Props = $props();
</script>

<Image id={imageId} {alt} />
```

## Media Feeds

Render story or post feeds with infinite scroll:

```svelte title="MediaFeed.svelte"
<script lang="ts">
  import {Feed} from "@rixl/media-svelte";

  interface Props {
    feedId: string;
  }

  let { feedId }: Props = $props();
</script>

<Feed {feedId} loop autoscroll />
```

## Handling Player Events

Pass event callback props to react to playback:

```svelte title="PlayerWithEvents.svelte"
<script lang="ts">
  import {Video} from "@rixl/media-svelte";

  let { videoId } = $props();
</script>

<Video
  id={videoId}
  analyticsPage="standalone"
  controls
  onPlay={() => console.log("Playback started")}
  onPause={() => console.log("Playback paused")}
/>
```

Available callbacks include `onPlay`, `onPause`, `onPausedChange`, `onEnded`, `onTimeUpdate`, `onLoadedMetadata`, `onError`, `onVolumeChange`, `onLoadingChange`, `onRateChange`, and `onQualityChange`. Set `analyticsPage` to `"feed"`, `"standalone"`, or `"profile"` to tag the view context.

The underlying player also dispatches a bubbling, composed `rixl-analytics` custom event carrying an `AnalyticsEvent` payload. Listen for it at the document level to inspect or forward analytics:

```ts
document.addEventListener("rixl-analytics", (e) => {
  console.log((e as CustomEvent).detail.event);
});
```

For details on the event taxonomy and core helpers, see [Analytics Integration](/en/sdk/media-react/video-component/analytics-integration) and [Core API](/en/sdk/media-core/core-api).

<Callout type="info">
  When using **SvelteKit** with SSR, ensure client-only logic executes inside `onMount` or behind a `browser` guard from `$app/environment`.
</Callout>
