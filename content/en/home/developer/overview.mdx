## Building with RIXL

You can integrate RIXL into your stack using two complementary approaches:

### 1. REST APIs

For backend ingestion, project configuration, and headless workflows. All API endpoints use standard HTTP methods, accept and return JSON payloads, and authenticate with project-scoped API keys.

- Base URL: `https://api.rixl.com`
- Full reference: [RIXL REST API Reference](/en/api)

### 2. Frontend SDKs

For dropping video players, responsive images, and infinite media feeds into your client apps with zero boilerplate.
