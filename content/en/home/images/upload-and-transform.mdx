## AVIF Optimization & ThumbHash Previews

**AVIF Optimization Settings**

- **Quality Level**: Balanced for the sweet spot between minimal size and visual perfection
- **Color Depth**: 8-bit for universal browser support
- **Smart Metadata**: Essential camera settings and color profiles preserved when useful
- **Auto-Rotation**: Images automatically display correctly based on their EXIF orientation data

**ThumbHash Previews**
Each processed image generates a compact ~25-byte ThumbHash placeholder that produces instant-loading previews while the full image downloads:

- **Zero extra network requests** – Easily embedded directly into initial page payloads or API responses
- **Instant rendering** – Immediate, flicker-free visual feedback
- **Color-accurate** – Faithfully preserves dominant colors and luminance
- **Smooth transitions** – Natural blur-to-sharp loading effect

## Best Practices

**When Uploading:**

- Upload your highest quality images, it'd optimize automatically
- Use clear, descriptive file names to stay organized
- Add alt text descriptions for screen readers

**When Loading Images:**

- Use our placeholder images for instant feedback while photos load
- Load images progressively for a better user experience
- Wait for processing to complete on large files
- Save processed image URLs to reduce API calls
