Every video and image has one state at a time. This page explains each state and what you can do while an item is in it.

---

## States

| State      | API status               | Meaning                                                           |
| ---------- | ------------------------ | ----------------------------------------------------------------- |
| Uploading  | `FILE_STATUS_UPLOADING`  | Waiting for the binary payload to arrive at the storage endpoint. |
| Uploaded   | `FILE_STATUS_UPLOADED`   | File received in storage; awaiting ingestion and processing.      |
| Processing | `FILE_STATUS_PROCESSING` | Media transcoding, optimization, and packaging in progress.       |
| Ready      | `FILE_STATUS_READY`      | Processing complete; media is published and ready for delivery.   |
| Failed     | `FILE_STATUS_ERROR`      | An error occurred during upload, ingestion, or transcoding.       |
| Deleted    | None                     | The item is removed from the dashboard and API (returns 404).     |

---

## Stopping a Transfer

Pausing an upload only affects the client-side binary transfer:

- The asset stays in `FILE_STATUS_UPLOADING` until the transfer resumes or the upload link expires.
- If the binary transfer completed before pausing, processing proceeds automatically.
- To cancel an unneeded upload, delete the media asset from the dashboard or API.

---

## Media Deletion

When an asset is deleted, it is immediately removed from your project library, and the API returns a 404 response.

| Asset State at Deletion | Processing Status     | Availability                   |
| ----------------------- | --------------------- | ------------------------------ |
| Uploaded                | Ingest canceled       | Not published                  |
| Processing              | Processing terminated | Not published                  |
| Ready or Failed         | Removed               | Removed from dashboard and API |

Storage quota updates may take a few moments to reflect recently deleted assets.

---

## Failed Items

If an asset encounters an error during processing:

- Check the asset details in the dashboard for failure indicators.
- Re-upload the source file or contact support if errors persist.
