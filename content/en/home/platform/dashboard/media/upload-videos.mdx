## Upload Workflow

<Steps>
  <Step>
    **Access Video Upload**

    Go to **Media → Videos** in your project dashboard.
  </Step>
  <Step>
    **Select Quality Tier**

    Choose a **Quality Tier**: Basic, Shorts, or Pro.
  </Step>
  <Step>
    **Configure Video Settings**

    Set metadata: title, description, tags, and project assignment.
  </Step>
  <Step>
    **Monitor Processing**

    Track progress with real-time transcoding updates.
  </Step>
</Steps>

---

## Quality Tiers

Choose the right processing tier for your content during upload:

- **Basic**: Standard web content (720p, efficient processing)
- **Shorts**: Optimized for mobile (1080p, 60fps support)
- **Pro**: High-quality production (4K support, premium features)

<Callout type="info">
  See full details in [Video Processing Quality Tiers](/en/home/platform/uploads/videos/quality-tiers).
</Callout>

## Media Library Features

Uploaded videos appear in the **Media Library** with:

- **Smart Categorization** - Automatic sorting by project, date, and content type
- **Thumbnail Management** - Custom thumbnails or auto-generated options
- **Batch Operations** - Bulk editing, moving, and tagging
- **Search & Filter** - Find videos quickly using metadata and processing status

**Dashboard Views:**
- **Processing Queue** - Monitor transcoding progress across all uploads
- **Video Gallery** - Playback previews with actions
- **Analytics View** - Processing time and file size analytics

## Automated Video Delivery

All videos uploaded to RIXL are processed automatically for web and mobile streaming:

- **Multi-quality renditions** matched to your selected tier
- **Adaptive HLS streaming** for uninterrupted playback across changing network speeds
- **Optimized compression** balancing compact file sizes with high visual fidelity
- **Automatic poster and thumbnail generation** for instant previews

For complete specifications, see the [video processing reference](/en/home/platform/uploads/videos-guide).
