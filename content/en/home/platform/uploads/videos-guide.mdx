## Processing Architecture

Video processing uses a three-phase pipeline converting uploaded content into streaming-ready assets:

<Steps>
  <Step>**Analysis & Planning** - Content analysis determines optimal rendition ladder</Step>
  <Step>**Multi-Quality Encoding** - Parallel transcoding to multiple resolutions and bitrates</Step>
  <Step>**Adaptive Stream Packaging** - HLS/DASH manifest generation for seamless delivery</Step>
</Steps>

## Processing Status Monitoring

Monitor your video's progress through the processing pipeline:

<Tabs items={['Status Types', 'API Monitoring']}>
  <Tab>
    `video.file.status` moves through:

    - **`FILE_STATUS_UPLOADING`** - Upload URLs issued, waiting for the bytes
    - **`FILE_STATUS_UPLOADED`** - Upload received, awaiting processing
    - **`FILE_STATUS_PROCESSING`** / **`FILE_STATUS_PREPARING`** - Being transcoded and packaged
    - **`FILE_STATUS_READY`** - Processing complete, available for streaming
    - **`FILE_STATUS_ERROR`** - Processing failed

  </Tab>
  <Tab>
    ```bash
    curl "https://api.rixl.com/media/v1/videos/{videoId}" \
      -H "X-API-Key: YOUR_PROJECT_API_KEY"
    ```

    The response is `{"video": {...}}`; read `video.file.status`. Poll every few seconds with backoff until it is `FILE_STATUS_READY` or `FILE_STATUS_ERROR`.

## Implementation Best Practices

**Quality Tier Selection:**

- **Basic**: Standard web content, bandwidth-conscious delivery
- **Shorts**: Mobile-first content, social media delivery
- **Pro**: Professional broadcasts, premium content experiences

**Processing Efficiency:**

- Upload during off-peak hours for faster processing
- Use recommended formats (MP4/H.264) to minimize processing time
- Monitor processing status rather than polling continuously
- Retry only as described in [Retries](/en/home/platform/api-documentation/error-handling#retries), and send an `Idempotency-Key` with the upload request

**Error Handling:**

<Tabs items={['TypeScript', 'Python', 'cURL']}>
  <Tab value="TypeScript">
    ```typescript
    const API = "https://api.rixl.com";
    const headers = {"X-API-Key": process.env.RIXL_API_KEY!, "Content-Type": "application/json"};

    async function uploadVideo(projectId: string, video: Blob, poster: Blob, name: string): Promise<string> {
      // One key per logical upload: a retry with the same key returns the same video_id.
      const idempotencyKey = crypto.randomUUID();
      let init: Response | undefined;
      for (let attempt = 0; attempt <= 3; attempt++) {
        init = await fetch(`${API}/media/v1/projects/${projectId}/videos/upload`, {
          method: "POST",
          headers: {...headers, "Idempotency-Key": idempotencyKey},
          body: JSON.stringify({name, video_quality: "VIDEO_QUALITY_PRO"}),
        });
        const retryAfter = init.headers.get("Retry-After");
        const transient = [502, 503, 504].includes(init.status) || (init.status === 409 && retryAfter !== null);
        if (!transient) break;
        await new Promise((r) => setTimeout(r, retryAfter ? Number(retryAfter) * 1000 : Math.random() * Math.min(8000, 500 * 2 ** attempt)));
      }
      if (!init?.ok) throw new Error(`upload init failed: ${init?.status} ${(await init?.json())?.error}`);
      const {video_id, video_upload_url, poster_upload_url} = await init.json();

      const puts = await Promise.all([
        fetch(video_upload_url, {method: "PUT", body: video}),
        fetch(poster_upload_url, {method: "PUT", body: poster}),
      ]);
      if (puts.some((r) => !r.ok)) throw new Error("upload to storage failed");
      return video_id;
    }
    ```

  </Tab>

  <Tab value="Python">
    ```python
    import os, uuid, requests

    API = "https://api.rixl.com"
    HEADERS = {"X-API-Key": os.environ["RIXL_API_KEY"]}

    def upload_video(project_id: str, video_path: str, poster_path: str) -> str:
        # Keep the key for this upload; reuse it if you retry the request.
        idempotency_key = str(uuid.uuid4())
        init = requests.post(
            f"{API}/media/v1/projects/{project_id}/videos/upload",
            headers={**HEADERS, "Idempotency-Key": idempotency_key},
            json={"name": os.path.basename(video_path), "video_quality": "VIDEO_QUALITY_PRO"},
            timeout=30,
        )
        init.raise_for_status()
        data = init.json()

        with open(video_path, "rb") as f:
            requests.put(data["video_upload_url"], data=f, timeout=600).raise_for_status()
        with open(poster_path, "rb") as f:
            requests.put(data["poster_upload_url"], data=f, timeout=60).raise_for_status()
        return data["video_id"]
    ```

  </Tab>
