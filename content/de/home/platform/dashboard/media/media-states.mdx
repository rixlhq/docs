Jedes Video und jedes Bild hat immer genau einen Status. Diese Seite erklärt jeden Status und was Sie in diesem Status tun können.

---

## Status

| Status | API-Status | Bedeutung |
|---|---|---|
| Wird hochgeladen | `FILE_STATUS_UPLOADING` | Die Datei wird noch erwartet. Die Übertragung läuft in Ihrem Browser oder Client. |
| In Warteschlange | `FILE_STATUS_UPLOADED` | Die Datei ist gespeichert und wartet auf den Start der Verarbeitung. |
| In Verarbeitung | `FILE_STATUS_PROCESSING`, `FILE_STATUS_PREPARING` | Die Verarbeitung hat begonnen. |
| Bereit | `FILE_STATUS_READY` | Das Element ist veröffentlicht und verfügbar. |
| Fehlgeschlagen | `FILE_STATUS_ERROR` | Die Verarbeitung ist fehlgeschlagen. |
| Gelöscht | Keiner | Das Element ist aus dem Dashboard und der API entfernt. Die API antwortet mit 404. |

Für die Verarbeitung gibt es noch kein Zeitlimit. Ein Element kann also in diesem Status bleiben, wenn ein Job hängen bleibt. Löschen Sie das Element in diesem Fall und laden Sie es erneut hoch.

---

## Übertragung anhalten

Das Pausieren eines Uploads betrifft nur die Übertragung. Ihr Browser sendet keine Daten mehr, und der Server erfährt davon nichts.

- Das Element bleibt im Status „Wird hochgeladen“ und wechselt zu „Fehlgeschlagen“, wenn der Upload-Link abläuft, bevor die Datei angekommen ist.
- Ist die Datei kurz vor dem Pausieren vollständig angekommen, wird sie normal verarbeitet.
- Für Uploads gibt es keine Schaltfläche zum Abbrechen.

Um sicherzugehen, dass ein Video nicht verarbeitet wird, löschen Sie es. Ein Bild kann erst gelöscht werden, wenn sein Upload abgeschlossen ist.

---

## Serverarbeit anhalten

Die Verarbeitung lässt sich weder pausieren noch abbrechen. Sie stoppen sie nur, indem Sie das Element löschen. Das Löschen kann nicht rückgängig gemacht werden.

| Löschen eines Elements im Status | Arbeit auf dem Server | Veröffentlicht? |
|---|---|---|
| In Warteschlange | Startet nie | Nein |
| In Verarbeitung | Verbleibende Schritte starten nicht. Der laufende Schritt wird beendet, sein Ergebnis wird verworfen | Nein |
| Bereit oder Fehlgeschlagen | Nichts zu stoppen | Aus dem Dashboard und der API entfernt |

Gelöschte Elemente können bis zu 15 Minuten weiter für Ihr Speicherkontingent zählen, weil die Kontingentprüfung eine zwischengespeicherte Summe verwendet. Bereits erfasste Upload-Nutzung wird nicht zurückgenommen.

<Callout type="warn">
  Beim Löschen werden gespeicherte Dateien nicht sofort entfernt, und ein vorhandener Direktlink zu einer Datei kann nach dem Löschen weiter funktionieren.
</Callout>

---

## Fehlgeschlagene Elemente

Ein fehlgeschlagener Job kann noch nicht wiederholt werden. Um die Datei erneut zu verarbeiten, löschen Sie das fehlgeschlagene Element und laden Sie die Datei erneut hoch.

Die Schaltfläche **Retry** auf der Detailseite eines Assets lädt nur die Seite neu. Sie startet die Verarbeitung nicht neu.
