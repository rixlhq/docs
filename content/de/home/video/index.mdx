## So transformiert RIXL Ihre Videos

<Steps>
  <Step>
    **Beliebiges Format hochladen**

    Laden Sie MP4, MOV, AVI, WebM oder jedes Videoformat hoch. RIXL akzeptiert Dateien mit bis zu je 2 GB.

  </Step>

  <Step>
    **Qualitätsstufe wählen**

    Wählen Sie Basic (720p), Shorts (1080p) oder Pro (4K) je nach Ihren Inhalten und den Anforderungen Ihrer Zielgruppe.

  </Step>

  <Step>
    **Automatische Verarbeitung**

    RIXL erstellt mehrere Qualitätsstufen, generiert Vorschaubilder und bereitet HLS-Streams automatisch vor.

  </Step>

  <Step>
    **Globale CDN-Auslieferung**

    Ihre verarbeiteten Videos werden an über 200 Edge-Standorte weltweit verteilt – für sofortiges Streaming überall.

  </Step>
</Steps>

## Qualitätsstufen

Wählen Sie die passende Verarbeitungsstufe für Ihre Inhalte und Ihre Zielgruppe:

<Tabs items={['Basic Tier', 'Shorts Tier', 'Pro Tier']}>
  <Tab value="Basic Tier">
    **Perfekt für:**
    - Web-Inhalte und Tutorials
    - Desktop-orientiertes Anschauen
    - Anforderungen an schnelle Verarbeitung
    - Bandbreitenschonende Auslieferung

    **Spezifikationen:**
    - Maximale Auflösung 720p HD
    - Bildraten 24 fps/30 fps
    - Schnellste Verarbeitungszeiten (~1x Videolänge)
    - Kleinste Dateigrößen
    - Ideal für Bildungsinhalte und Webvideos

  </Tab>

  <Tab value="Shorts Tier">
    **Perfekt für:**
    - Social-Media-Inhalte
    - Mobile-First-Erlebnisse
    - Vertikale Videoinhalte
    - Flüssige 60-fps-Bewegung

    **Spezifikationen:**
    - Maximal 1080p Full HD
    - Bildraten bis zu 60 fps
    - Mobil-taugliche Kodierung
    - Mittlere Verarbeitungszeiten (~1,5x Videolänge)
    - Perfekt für Social-Plattformen und mobiles Anschauen

  </Tab>

  <Tab value="Pro Tier">
    **Perfekt für:**
    - Professionelle Ausstrahlungen
    - 4K-/HDR-Inhalte
    - Premium-Streaming-Erlebnisse
    - Ausgabe in Produktionsqualität

    **Spezifikationen:**
    - Unterstützung von 4K Ultra HD
    - Bis zu 60 fps mit HDR
    - Professionelle Audioverarbeitung
    - Längste Verarbeitungszeiten (~2–3x Videolänge)
    - Ausgabe in Kinoqualität für Premium-Inhalte

  </Tab>
</Tabs>

  </Tab>

  <Tab value="Mit Analytics">
    ```jsx

      return (
        <Video

          className="w-full h-auto rounded-lg"
          controls
          analytics

          onRixlAnalytics={(e) => console.log(e.detail.event)}

    ```

  </Tab>

  <Tab value="Lit / HTML">
    ```html
    <script type="module">
      import '@rixl/media-lit/video.js';
    </script>

    <rixl-video
      video-id="your-video-id"
      analytics
      analytics-page="video"
      controls
    ></rixl-video>
    ```

  </Tab>
</Tabs>

<Callout type="info">
  Die React-`Video`-Komponente ist ein `@lit/react`-Wrapper um `<rixl-video>`. Sie leitet Standard-`<video>`-Attribute (`autoPlay`, `muted`, `loop`, `controls`, `className`) sowie Analytics-Props und das `onRixlAnalytics`-Event weiter. Legacy-UI-Props wie `progressBar`, `allowFullscreen`, `heatmap` und `chapters` werden nicht mehr an das Lit-Element weitergegeben.
</Callout>

### API-Integration

<Tabs items={['Upload Video', 'Get Video Details', 'List Videos']}>
  <Tab value="Upload Video">
    ```javascript
    const uploadVideo = async (projectId, videoFile, qualityTier = 'pro') => {
      const initResponse = await fetch(
        `https://api.rixl.com/media/v1/projects/${projectId}/videos/upload`,
        {
          method: 'POST',
          headers: {
            'Authorization': 'Bearer YOUR_API_TOKEN',
            'Content-Type': 'application/json'
          },
          body: JSON.stringify({
            name: videoFile.name,
            video_quality: qualityTier,
            image_format: 'jpg'
          })
        }
      );

      const {
        video_id,
        video_upload_url,
        poster_id,
        poster_upload_url,
        expires_at
      } = await initResponse.json();

      await fetch(video_upload_url, {
        method: 'PUT',
        body: videoFile,
        headers: { 'Content-Type': videoFile.type }
      });

      return { video_id, poster_id, expires_at };
    };
    ```

  </Tab>

  <Tab value="Get Video Details">
    ```javascript
    const getVideoDetails = async (videoId) => {
      const response = await fetch(
        `https://api.rixl.com/media/v1/videos/${videoId}`,
        { headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' } }
      );

      const { data } = await response.json();
      return {
        id: data.id,
        duration: data.duration,
        width: data.width,
        height: data.height,
        streamingUrl: data.file.url,
        posterUrl: data.poster?.file?.url,
        status: data.file.status,
        createdAt: data.created_at
      };
    };
    ```

  </Tab>

  <Tab value="List Videos">
    ```javascript
    const listVideos = async (projectId) => {
      const response = await fetch(
        `https://api.rixl.com/media/v1/projects/${projectId}/videos`,
        { headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' } }
      );

      const { data } = await response.json();
      return data.videos ?? [];
    };
    ```

  </Tab>
</Tabs>
