## So transformiert RIXL Ihre Bilder

<Steps>
  <Step>
    **Beliebiges Format hochladen**

    Laden Sie JPEG, PNG, WebP, HEIC oder jedes gängige Bildformat hoch. RIXL akzeptiert Dateien mit bis zu je 100 MB.
  </Step>

  <Step>
    **Automatische AVIF-Konvertierung**

    Jedes Bild wird in das AVIF-Format konvertiert – für 50 % kleinere Dateigrößen ohne sichtbaren Qualitätsverlust.
  </Step>

  <Step>
    **Intelligente Platzhaltergenerierung**

    Sofortige Blur-Platzhalter werden erstellt, um während des Ladens der vollständigen Bilder ein reibungsloses Ladeerlebnis zu bieten.
  </Step>

  <Step>
    **Globale CDN-Auslieferung**

    Ihre Bilder werden an über 200 Edge-Standorte weltweit verteilt – für sofortiges Laden überall.
  </Step>
</Steps>

## Unterstützte Formate

### Eingabeformate
RIXL akzeptiert alle gängigen Bildformate zur Verarbeitung:

<Columns cols={3}>
  <Card title="Gängige Formate" icon="image">

  </Card>
  <Card title="Professionelle Formate" icon="camera">
    HEIC/HEIF, TIFF, JPEG 2000 – hochwertige Formate von Kameras und professionellen Tools.
  </Card>
  <Card title="Vektorgrafiken" icon="layers">
    SVG-Dateien werden unverändert beibehalten, für gestochen scharfe Skalierung in jeder Größe.
  </Card>
</Columns>

### Ausgabevorbereitung
Jedes Bild wird automatisch für die Web-Auslieferung vorbereitet:

- **Primär:** AVIF-Format (50 % kleiner als JPEG)
- **Fallback:** WebP-Format (30 % kleiner als JPEG)
- **Legacy:** JPEG-Format (universelle Kompatibilität)
- **Platzhalter:** Sofortige Blur-Platzhalter für reibungsloses Laden

### API-Integration

<Tabs items={['Upload Image', 'Get Image Details', 'List Images']}>
  <Tab value="Upload Image">
    ```javascript
    const uploadImage = async (projectId, imageFile) => {
      const initResponse = await fetch(
        `https://api.rixl.com/media/v1/projects/${projectId}/images/upload`,
        {
          method: 'POST',
          headers: {
            'Authorization': 'Bearer YOUR_API_TOKEN',
            'Content-Type': 'application/json'
          },
          body: JSON.stringify({ name: imageFile.name, format: 'jpg' })
        }
      );

      const { image_id, upload_url, expires_at } = await initResponse.json();

      await fetch(upload_url, {
        method: 'PUT',
        body: imageFile
      });

      return { image_id, expires_at };
    };
    ```
  </Tab>

  <Tab value="Get Image Details">
    ```javascript
    const getImageDetails = async (imageId) => {
      const response = await fetch(
        `https://api.rixl.com/media/v1/images/${imageId}`,
        { headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' } }
      );

      const { data } = await response.json();
      return data;
    };
    ```
  </Tab>

  <Tab value="List Images">
    ```javascript
    const listImages = async (projectId) => {
      const response = await fetch(
        `https://api.rixl.com/media/v1/projects/${projectId}/images`,
        { headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' } }
      );

      const { data } = await response.json();
      return data.images ?? [];
    };
    ```
  </Tab>
