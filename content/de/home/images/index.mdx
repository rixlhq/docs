## Supported Formats

### Input Formats

RIXL accepts all common image formats for processing:

  <Card title="Common Formats" icon="image">
    JPEG, PNG, WebP, GIF, BMP - the formats you use every day.
  </Card>
  <Card title="Professional Formats" icon="camera">
    HEIC/HEIF, TIFF, JPEG 2000 - high-quality formats from cameras and professional tools.
  </Card>
  <Card title="Vector Graphics" icon="layers">
    SVG files are preserved as-is for crisp scaling at any size.
  </Card>
</Columns>

### Output Preparation

Every image is automatically prepared for web delivery:

- **Primary:** AVIF format (50% smaller than JPEG)
- **Fallback:** WebP format (30% smaller than JPEG)
- **Legacy:** JPEG format (universal compatibility)
- **Placeholders:** Instant blur placeholders for smooth loading

## Implementation Examples

### React Component Usage

<Tabs items={['Basic Usage', 'With Analytics', 'Lit / HTML']}>
  <Tab value="Basic Usage">
    ```jsx
    import {Image} from '@rixl/media-react';

    function ProfilePhoto({imageId}) {
      return (
        <Image
          id={imageId}
          className="w-32 h-32 rounded-full object-cover"
        />

    }
    ```

  </Tab>

  <Tab value="With Analytics">
    ```jsx
    import {Image} from '@rixl/media-react';

    function ProfilePhoto({imageId}) {
      return (
        <Image
          id={imageId}
          className="w-32 h-32 rounded-full object-cover"
          analytics
          analyticsPage="profile"
          onRixlAnalytics={(e) => console.log(e.detail.event)}
        />
      );
    }
    ```

  </Tab>

  <Tab value="Lit / HTML">
    ```html
    <script type="module">
      import '@rixl/media-lit/image.js';
    </script>

    <rixl-image
      image-id="your-image-id"
      analytics
      analytics-page="profile"
    ></rixl-image>
    ```

  </Tab>
</Tabs>

<Callout type="info">
  The React `Image` component is a `@lit/react` wrapper around `<rixl-image>`. It accepts `id` (mapped to `imageId`), `imageData`, `alt`, `className`, and analytics props (`analytics`, `analyticsPage`, `feedId`, `postId`, `onRixlAnalytics`). `alt` is forwarded and used as the `alt` attribute on the rendered `<img>`.
</Callout>

### API Integration

<Tabs items={['Upload Image', 'Get Image Details', 'List Images']}>
  <Tab value="Upload Image">
    ```javascript
    const uploadImage = async (projectId, imageFile) => {
      const initResponse = await fetch(
        `https://api.rixl.com/media/v1/projects/${projectId}/images/upload`,
        {
          method: 'POST',
          headers: {
            'Authorization': 'Bearer YOUR_API_TOKEN',
            'Content-Type': 'application/json'
          },
          body: JSON.stringify({ name: imageFile.name, format: 'jpg' })
        }
      );

      const { image_id, upload_url, expires_at } = await initResponse.json();

      await fetch(upload_url, {
        method: 'PUT',
        body: imageFile
      });

      return { image_id, expires_at };
    };
    ```

  </Tab>

  <Tab value="Get Image Details">
    ```javascript
    const getImageDetails = async (imageId) => {
      const response = await fetch(
        `https://api.rixl.com/media/v1/images/${imageId}`,
        { headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' } }
      );

      const { data } = await response.json();
      return data;
    };
    ```

  </Tab>

  <Tab value="List Images">
    ```javascript
    const listImages = async (projectId) => {
      const response = await fetch(
        `https://api.rixl.com/media/v1/projects/${projectId}/images`,
        { headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' } }
      );

      const { data } = await response.json();
      return data.images ?? [];
    };
    ```

  </Tab>
</Tabs>
