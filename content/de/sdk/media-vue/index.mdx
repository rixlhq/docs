RIXL bietet framework-freie Webkomponenten über `@rixl/media-lit` und zustandsbasiertes Management über `@rixl/media`. Vue 3 verfügt über erstklassige native Unterstützung für Custom Elements, sodass du `<rixl-video>`, `<rixl-image>` und `<rixl-feed>` direkt in jeder Vue- oder Nuxt-Anwendung mit reaktiven Props und Event-Listenern verwenden kannst.

## Installation

Installiere `@rixl/media-lit` zusammen mit dem Basispaket `@rixl/media`:

```bash
npm install @rixl/media-lit @rixl/media
```

## Vite-Konfiguration

Konfiguriere Vue so, dass `rixl-*`-Tags als benutzerdefinierte Elemente erkannt werden:

```ts title="vite.config.ts"
import vue from "@vitejs/plugin-vue";
import {defineConfig} from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: {
          isCustomElement: (tag) => tag.startsWith("rixl-"),
        },
      },
    }),
  ],
});
```

<Callout type="info">
  Wenn du **Nuxt 3** nutzt, konfiguriere `vue.compilerOptions.isCustomElement` in deiner `nuxt.config.ts` im Bereich `vue`.
</Callout>

## Authentifizierung

Initialisiere den RIXL-Client einmalig beim Start der Anwendung:

```ts
import {connect} from "@rixl/media";

await connect({
  baseUrl: "https://api.rixl.com",
  apiKey: "your-api-key",
});
```

## Videoplayer

Importiere das `@rixl/media-lit/video`-Element und binde deine Video-ID dynamisch ein:

```vue title="VideoPlayer.vue"
<script setup lang="ts">
import "@rixl/media-lit/video";

defineProps<{
  videoId: string;
}>();
</script>

<template>
  <div class="video-container">
    <rixl-video :video-id="videoId" autoplay controls />
  </div>
</template>
```

## Reaktive Bilder

Importiere `@rixl/media-lit/image` für optimierte, responsive Bilder:

```vue title="ImageViewer.vue"
<script setup lang="ts">
import "@rixl/media-lit/image";

defineProps<{
  imageId: string;
}>();
</script>

<template>
  <rixl-image :image-id="imageId" alt="Medien-Asset" />
</template>
```

## Medien-Feeds

Zeige Infinite-Scroll-Feeds oder Story-Karussells mit `<rixl-feed>` an:

```vue title="MediaFeed.vue"
<script setup lang="ts">
import "@rixl/media-lit/feed";

defineProps<{
  feedId: string;
}>();
</script>

<template>
  <rixl-feed :feed-id="feedId" loop autoscroll />
</template>
```

## Events & Analytics

Die Komponenten senden native Custom Events, die über Vues `@`-Syntax empfangen werden können:

```vue title="AnalyticsExample.vue"
<script setup lang="ts">
import "@rixl/media-lit/video";

function handleAnalytics(event: CustomEvent) {
  console.log("Playback-Event:", event.detail);
}
</script>

<template>
  <rixl-video video-id="vid_123" @rixl-analytics="handleAnalytics" />
</template>
```
