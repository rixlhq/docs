RIXL-Medienkomponenten basieren auf standardisierten Web Components über `@rixl/media-lit` und bieten nahtlose Interoperabilität mit Svelte 4 und Svelte 5. Du kannst `<rixl-video>`, `<rixl-image>` und `<rixl-feed>` wie gewohnte HTML-Elemente mit reaktiven Bindings nutzen.

## Installation

Installiere die Webkomponenten-Bibliothek und den Headless-Client:

```bash
npm install @rixl/media-lit @rixl/media
```

## Authentifizierung

Verbinde dich beim Start der Anwendung oder im Root-Layout mit RIXL:

```ts
import {connect} from "@rixl/media";

await connect({
  baseUrl: "https://api.rixl.com",
  apiKey: "your-api-key",
});
```

## Videoplayer

Importiere das `@rixl/media-lit/video`-Element in deiner Svelte-Komponente:

```svelte title="VideoPlayer.svelte"
<script lang="ts">
  import "@rixl/media-lit/video";

  interface Props {
    videoId: string;
    autoplay?: boolean;
    controls?: boolean;
  }

  let { videoId, autoplay = false, controls = true }: Props = $props();
</script>

<div class="player-wrapper">
  <rixl-video
    video-id={videoId}
    {autoplay}
    {controls}
  />
</div>
```

## Reaktive Bilder

Bilder mit automatischer Formatoptimierung und Lazy-Loading rendern:

```svelte title="ImageViewer.svelte"
<script lang="ts">
  import "@rixl/media-lit/image";

  interface Props {
    imageId: string;
    alt?: string;
  }

  let { imageId, alt = "Medien-Element" }: Props = $props();
</script>

<rixl-image
  image-id={imageId}
  {alt}
/>
```

## Medien-Feeds

Feeds oder Story-Karussells mit Endlos-Scroll anzeigen:

```svelte title="MediaFeed.svelte"
<script lang="ts">
  import "@rixl/media-lit/feed";

  interface Props {
    feedId: string;
  }

  let { feedId }: Props = $props();
</script>

<rixl-feed
  feed-id={feedId}
  loop
  autoscroll
/>
```

## Analytics-Events verarbeiten

Reagiere auf Wiedergabe-Events des Players:

```svelte title="PlayerWithAnalytics.svelte"
<script lang="ts">
  import "@rixl/media-lit/video";

  let { videoId } = $props();

  function onAnalytics(event: CustomEvent) {
    console.log("Analytics-Event:", event.detail);
  }
</script>

<rixl-video
  video-id={videoId}
  onrixl-analytics={onAnalytics}
  controls
/>
```

<Callout type="info">
  Bei Verwendung von **SvelteKit** mit serverseitigem Rendering (SSR) sollte die Registrierung der Custom Elements innerhalb von `onMount`
  oder abgesichert durch `browser` aus `$app/environment` erfolgen.
</Callout>
