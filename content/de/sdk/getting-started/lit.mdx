Das Paket `@rixl/media-lit` stellt framework-freie Web Components bereit, die mit [Lit](https://lit.dev/) gebaut wurden. Jede Komponente ist als tree-shakebarer Subpath-Import verfügbar, sodass Sie nur die Komponente laden, die Sie verwenden. React-, Svelte-, Vue- und Angular-Wrapper setzen auf denselben Lit-Komponenten auf.

<Callout type="info">
  Die gesamte UI- und Analytics-Instrumentierung lebt in Lit. Framework-Wrapper sind dünne Adapter, die `onRixlAnalytics` exponieren und
  alte Prop-Namen mappen.
</Callout>

## Installation

```bash
npm install @rixl/media-lit
```

Falls Ihr Paketmanager sie nicht automatisch installiert, benötigen Sie auch die Peer Dependencies (`lit`, `hls.js`, `@rixl/media` und `nanostores`).

## Authentifizierung

Standalone-Apps müssen `connect()` einmal aufrufen, bevor eine Medienkomponente gerendert wird:

```ts
import {connect} from "@rixl/media";

await connect({
  baseUrl: "https://api.rixl.com",
  apiKey: "your-rixl-api-key",
});
```

`connect` initialisiert den gemeinsamen `@rixl/sdk` HTTP-Client und befüllt den Analytics-Kontext (`device`, `session`, `navigator` und Locale). Sie können auch selbst `initializeAnalyticsContext()` aufrufen, bevor ein Analytics-Event ausgelöst wird.

Wenn Ihre Host-App bereits `@rixl/sdk` nutzt und `connect()` für eigene API-Aufrufe verwendet, wiederverwenden die Medienkomponenten automatisch denselben authentifizierten Client.

## Komponenten verwenden

Importieren Sie einzelne Komponenten aus ihrem Subpath. Dadurch wird nur diese Komponente und ihre gemeinsamen Abhängigkeiten geladen.

### Image

```html
<script type="module">
  import "@rixl/media-lit/image";
</script>

<rixl-image image-id="your-image-id"></rixl-image>
```

### Video

```html
<script type="module">
  import "@rixl/media-lit/video";
</script>

<!-- Lade per RIXL Video-ID -->
<rixl-video video-id="your-video-id"></rixl-video>

<!-- Oder übergib eine direkte HLS-URL -->
<rixl-video src="https://example.com/stream.m3u8"></rixl-video>
```

### Feed

```html
<script type="module">
  import "@rixl/media-lit/feed";
</script>

<rixl-feed feed-id="your-feed-id"></rixl-feed>
```

## Verfügbare Subpaths

| Subpath                 | Komponente     | Registriert                                                             |
| ----------------------- | -------------- | ----------------------------------------------------------------------- |
| `@rixl/media-lit/image` | `<rixl-image>` | Image-Komponente mit Lazy Loading und View-Analytics                    |
| `@rixl/media-lit/video` | `<rixl-video>` | Video-Komponente mit HLS-Setup sowie Interaktions- und Fehler-Analytics |
| `@rixl/media-lit/feed`  | `<rixl-feed>`  | Infinite-Scroll-Feed mit Bild- und Videoposts und Feed-Level-Analytics  |

Der Standard-Barrel-Import (`@rixl/media-lit`) registriert ebenfalls alle drei Komponenten, wenn Sie Bequemlichkeit über Bundle-Splitting stellen.

## Komponenten-Attribute

### `<rixl-image>`

| Attribut         | Typ                                   | Erforderlich | Standard       | Beschreibung                           |
| ---------------- | ------------------------------------- | ------------ | -------------- | -------------------------------------- |
| `image-id`       | `string`                              | Ja           | —              | RIXL Image-ID                          |
| `analytics`      | `boolean`                             | Nein         | `true`         | Analytics aktivieren                   |
| `analytics-page` | `"feed" \| "standalone" \| "profile"` | Nein         | `"standalone"` | Kontext der Ansicht                    |
| `feed-id`        | `string`                              | Nein         | `""`           | Feed-ID, wenn innerhalb eines Feeds    |
| `post-id`        | `string`                              | Nein         | `""`           | Post-ID, wenn innerhalb eines Feeds    |
| `is-current`     | `boolean`                             | Nein         | `false`        | Ob dieser Post aktuell im Viewport ist |

### `<rixl-video>`

| Attribut         | Typ                                   | Erforderlich                    | Standard       | Beschreibung                         |
| ---------------- | ------------------------------------- | ------------------------------- | -------------- | ------------------------------------ |
| `video-id`       | `string`                              | Eines von `video-id` oder `src` | —              | RIXL Video-ID                        |
| `src`            | `string`                              | Eines von `video-id` oder `src` | —              | Direkte HLS-/Video-URL               |
| `analytics`      | `boolean`                             | Nein                            | `true`         | Analytics aktivieren                 |
| `analytics-page` | `"feed" \| "standalone" \| "profile"` | Nein                            | `"standalone"` | Kontext der Ansicht                  |
| `feed-id`        | `string`                              | Nein                            | `""`           | Feed-ID, wenn innerhalb eines Feeds  |
| `post-id`        | `string`                              | Nein                            | `""`           | Post-ID, wenn innerhalb eines Feeds  |
| `is-current`     | `boolean`                             | Nein                            | `false`        | Aktueller Feed-Post                  |
| `autoplay`       | `boolean`                             | Nein                            | `true`         | Automatisch abspielen, wenn sichtbar |
| `muted`          | `boolean`                             | Nein                            | `true`         | Stumm starten                        |

Die `<rixl-video>`-Komponente rendert ein Standard-`<video>`-Element mit Browser-Controls und kümmert sich bei Bedarf über `hls.js` um HLS.

### `<rixl-feed>`

| Attribut         | Typ                                   | Erforderlich | Standard | Beschreibung                                     |
| ---------------- | ------------------------------------- | ------------ | -------- | ------------------------------------------------ |
| `feed-id`        | `string`                              | Ja           | —        | RIXL Feed-ID                                     |
| `loop`           | `boolean`                             | Nein         | `false`  | Nach dem letzten Post wieder beim ersten starten |
| `autoscroll`     | `boolean`                             | Nein         | `false`  | Automatisch zum nächsten Post weiterschalten     |
| `analytics`      | `boolean`                             | Nein         | `true`   | Analytics aktivieren                             |
| `analytics-page` | `"feed" \| "standalone" \| "profile"` | Nein         | `"feed"` | Kontext der Ansicht                              |
| `limit`          | `number`                              | Nein         | `10`     | Posts pro Fetch                                  |
| `buffer`         | `number`                              | Nein         | `2`      | Off-screen gehaltene Posts                       |

## Analytics-Events

Alle Lit-Komponenten dispatchen ein bubblendes, composed `rixl-analytics` Custom Event. Das Payload ist ein `AnalyticsEvent`:

```html
<script type="module">
  import "@rixl/media-lit/image";

  document.addEventListener("rixl-analytics", (e) => {
    console.log(e.detail.event);
  });
</script>

<rixl-image image-id="your-image-id"></rixl-image>
```

Sie können den Listener auch direkt am Element anbringen:

```js
const image = document.querySelector("rixl-image");
image.addEventListener("rixl-analytics", (e) => {
  console.log(e.detail.event);
});
```

Details zur Event-Taxonomie und den Core-Helfern finden Sie unter [Analytics Integration](/de/sdk/video-component/analytics-integration) und [Core API](/de/sdk/core-api).

## Framework-Wrapper

`@rixl/media-react` ist ein dünner React-Wrapper um dieselben Lit-Komponenten. Verwenden Sie ihn in React-Apps; für andere Frameworks oder Vanilla JS nutzen Sie `@rixl/media-lit` direkt. Zukünftige Svelte-, Vue- und Angular-Wrapper folgen demselben Muster.
