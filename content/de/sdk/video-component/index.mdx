## Overview

The `Video` component plays RIXL video content using adaptive HLS streaming. It is implemented as a Lit web component (`<rixl-video>`) and wrapped for React so analytics and playback behavior are consistent across every framework.

The component renders a standard HTML `<video>` element and uses `hls.js` for HLS support where native support is missing. It tracks `content_views`, engagement, interaction, and error events automatically.

### Quick Example

```tsx
import {Video} from "@rixl/media-react";

function Player() {
  return (
    <Video
      id="your-video-id"
      className="w-full h-auto rounded-lg"
      analyticsPage="standalone"
      onRixlAnalytics={(e) => console.log(e.detail.event)}
    />
  );
}
```

### Key Capabilities

**Streaming & Playback**

- HLS playback with automatic `hls.js` fallback
- Muted autoplay by default for browser compliance
- Standard `<video>` element controls
- `src` override for direct streams

**Analytics**

- `content_views` `start`/`watch`/`end` events with segments
- Interaction events: `play`, `pause`, `seek`, `mute`, `volume_change`, `fullscreen`, `picture_in_picture`, `quality_change`, `settings_open`
- Error events: `video_load_error`, `video_api_error`, and `hls_*` errors
- `feed_id`, `post_id`, and `page` context support

**Customization**

- CSS class customization through `className`
- Responsive design with aspect ratio preservation

<Callout type="info">
  The React wrapper still accepts legacy UI props (`theme`, `progressBar`, `allowFullscreen`, etc.) for backward compatibility, but they are not forwarded to the Lit element. Use `className` and the browser `<video>` controls for current  behavior.
</Callout>

### Custom Controls

Need custom controls instead of the built-in browser UI? Use the public [Hooks](/en/sdk/hooks) section.

The supported pattern is:

- Detached sibling controls inside `<VideoPlayer>`
- The player-scope hooks (`usePlayback`, `usePlayerProgress`, etc.) bind to the enclosing player scope, not directly to the Lit-backed `<Video>`

The new `<Video>` is a self-contained custom element. Custom controls can also be built by listening to `onRixlAnalytics` and driving a separate `<video>` element if necessary.

### When to Use

The Video component is perfect for:

- **Content platforms** requiring professional video playback
- **E-learning applications** with adaptive streaming
- **Marketing websites** needing background or promotional videos
- **Documentation sites** with instructional video content
- **Mobile-first applications** requiring adaptive streaming

### Browser Support

Works seamlessly across all modern browsers. `hls.js` provides HLS playback support where native support is absent.
