<Callout type="info">
  Die React-`Video`-Komponente ist ein `@lit/react`-Wrapper um das Lit-Element `<rixl-video>`. Sie rendert ein Standard-HTML-`<video>`-Element und verwendet daher die nativen Browser-Steuerelemente, wenn `controls` gesetzt ist. Benutzerdefinierte Steuerleisten können mit der Scope-basierten `VideoPlayer`- und Hooks-API aus [Hooks](/de/sdk/hooks) oder durch das Abhören von `onRixlAnalytics` aufgebaut werden.
</Callout>

## Standard-Video-Attribute

Da `<rixl-video>` und der React-`Video`-Wrapper das zugrunde liegende HTML-`<video>`-Element verfügbar machen, können Sie alle Standard-Media-Attribute verwenden:

| Attribut      | Typ                              | Beschreibung                                                                                        |
| ------------- | -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `controls`    | `boolean`                        | Zeigt die Standard-Steuerleiste des Browsers (Wiedergabe, Pause, Suche, Lautstärke, Vollbild usw.). |
| `autoPlay`    | `boolean`                        | Startet die Wiedergabe, sobald das Video abspielbar ist.                                            |
| `muted`       | `boolean`                        | Schaltet Audio standardmäßig stumm.                                                                 |
| `loop`        | `boolean`                        | Wiederholt die Wiedergabe am Ende.                                                                  |
| `playsInline` | `boolean`                        | Bevorzugt Inline-Wiedergabe auf mobilen Browsern.                                                   |
| `poster`      | `string`                         | URL eines Vorschaubilds, das vor dem Laden angezeigt wird.                                          |
| `preload`     | `"none" \| "metadata" \| "auto"` | Steuert, wie viel des Videos vorgeladen wird.                                                       |

```tsx
import {Video} from "@rixl/media-react";

<Video id="your-video-id" className="w-full h-auto rounded-lg" controls autoPlay={false} muted loop />;
```

## Native Steuerleiste

Wenn `controls` gesetzt ist, rendert der Browser seine eigene Steuerleiste. Das genaue Aussehen und die Fähigkeiten hängen vom Browser ab, umfassen aber typischerweise:

- **Wiedergabe / Pause**
- **Suchleiste**
- **Lautstärkeregler**
- **Stummschalten / Entstummen**
- **Vollbild**
- **Bild-in-Bild** (in unterstützten Browsern)

<Callout type="info">
  Funktionen wie Wiedergabegeschwindigkeits-Voreinstellungen, Untertitel-Styling, mehrere Tonspuren und Kapitelmarken werden vom Browser verwaltet, sofern das zugrunde liegende `<video>`-Element sie unterstützt. Die Rixl-`Video`-Komponente fügt derzeit kein eigenes Einstellungsmenü über den nativen Steuerelementen hinzu.
</Callout>

## Analytics-Events

Die Video-Komponente gibt `rixl-analytics`-Events über `onRixlAnalytics` aus. Diese Events beschreiben die Interaktionen der Nutzer mit dem Player:

| Event                  | Typ             | Beschreibung                                                 |
| ---------------------- | --------------- | ------------------------------------------------------------ |
| `content_view` `start` | `content_views` | Das Video ist in den Viewport geraten und wird getrackt.     |
| `content_view` `watch` | `content_views` | Periodischer View-Heartbeat, solange das Video sichtbar ist. |
| `content_view` `end`   | `content_views` | Das Video hat den Viewport verlassen oder wurde entfernt.    |
| `play`                 | `interaction`   | Der Nutzer hat die Wiedergabe gestartet.                     |
| `pause`                | `interaction`   | Der Nutzer hat die Wiedergabe pausiert.                      |
| `seek`                 | `interaction`   | Der Nutzer hat zu einer neuen Position gesprungen.           |
| `mute` / `unmute`      | `interaction`   | Audio wurde stummgeschaltet oder aktiviert.                  |
| `volume_change`        | `interaction`   | Die Lautstärke hat sich geändert.                            |
| `fullscreen`           | `interaction`   | Vollbildmodus wurde betreten oder verlassen.                 |
| `picture_in_picture`   | `interaction`   | Bild-in-Bild-Modus wurde betreten oder verlassen.            |
| `quality_change`       | `interaction`   | Die HLS-Qualitätsstufe hat sich geändert.                    |
| `settings_open`        | `interaction`   | Das native Einstellungsmenü wurde geöffnet.                  |
| `error`                | `error`         | Ein Fehler beim Laden oder Abspielen ist aufgetreten.        |

```tsx
import {Video} from "@rixl/media-react";

<Video
  id="your-video-id"
  controls
  analytics
  analyticsPage="video"
  onRixlAnalytics={(e) => {
    console.log("Rixl analytics event:", e.detail.event);
  }}
/>;
```

## Benutzerdefinierte Steuerleisten

Für eine vollständig benutzerdefinierte Steuerleiste gibt es zwei empfohlene Wege:

1. **Scope-basierte Hooks** — Verwenden Sie `<VideoPlayer>` mit `usePlayback`, `usePlayerProgress` und `useMediaSettings`. Dies ist die legacy React-Player-API und in [Hooks](/de/sdk/hooks) dokumentiert.
2. **Geschwister-Elemente + `onRixlAnalytics`** — Platzieren Sie eigene Steuerelemente als Geschwister von `<Video>` und steuern Sie diese anhand der Analytics-Events, Ihres eigenen React-States oder eines gewrappten nativen `<video>`-Elements.

<Callout type="warning">
  Rendern Sie keine benutzerdefinierten Steuerelemente als Kinder der `Video`-Komponente. Der `Video`-Wrapper ist eine in sich geschlossene
  Lit-Webkomponente und stellt keinen internen Player-Scope für untergeordnete Steuerelemente bereit.
</Callout>

## Tastaturkürzel

Wenn das Video-Element den Fokus hat, unterstützen Browser in der Regel die folgenden Kürzel auf der nativen `<video>`-Steuerleiste:

| Aktion                     | Kürzel                |
| -------------------------- | --------------------- |
| Wiedergabe / Pause         | `Leertaste` oder `K`  |
| 5 s vorwärts springen      | `→`                   |
| 5 s zurück springen        | `←`                   |
| Lautstärke erhöhen         | `↑`                   |
| Lautstärke verringern      | `↓`                   |
| Stummschalten / Entstummen | `M`                   |
| Vollbild umschalten        | `F`                   |
| Bild-in-Bild umschalten    | `I` (browserabhängig) |

## Bild-in-Bild und Vollbild

Bild-in-Bild und Vollbild werden über die native Steuerleiste des Browsers ausgelöst oder durch Aufruf der Standard-`<video>`-APIs auf einer Ref:

```tsx
import {useRef} from "react";
import {Video} from "@rixl/media-react";

function Player({videoId}) {
  const ref = useRef(null);

  return (
    <>
      <Video ref={ref} id={videoId} controls className="w-full h-auto" />
      <button onClick={() => ref.current?.requestFullscreen?.()}>Vollbild</button>
    </>
  );
}
```

<Callout type="info">
  Nicht alle Browser unterstützen Bild-in-Bild. Die `Video`-Komponente gibt ein `picture_in_picture` Analytics-Interaction-Event aus, wenn
  der Browser die entsprechenden `enterpictureinpicture`- / `leavepictureinpicture`-Events feuert.
</Callout>
