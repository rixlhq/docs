## What's Included

**Available:**

- Native browser video controls
- Responsive sizing
- Analytics events (`content_views`, `interaction`, `error`)

**No longer supported as props:**

- `theme`
- `progressBar`
- `allowFullscreen`
- `allowPlayPause`
- `heatmap`
- `chapters`
- `resumeProgress`

These legacy props are accepted for backward compatibility but are not forwarded to the Lit element.

## Analytics Events

The player emits these analytics events through `onRixlAnalytics`:

- `content_views` - `start`, `watch`, `end`
- `interaction` - `play`, `pause`, `seek`, `mute`, `volume_change`, `fullscreen`, `picture_in_picture`, `quality_change`, `settings_open`
- `error` - `video_element_error`, `hls_error`, `video_api_error`

## Best Practices

<Callout type="info">Use `analyticsPage` to set the page context (`"feed"`, `"standalone"`, `"profile"`).</Callout>

<Callout type="info">Subscribe to `onRixlAnalytics` to process or forward analytics events to your own pipeline.</Callout>

<Callout type="warning">
  Avoid passing legacy UI props; the `Video` wrapper is a thin Lit wrapper and does not implement custom controls.
</Callout>
