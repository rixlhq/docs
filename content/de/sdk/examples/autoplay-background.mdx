## Key Features

- **Muted Autoplay**: Complies with browser autoplay policies
- **Seamless Loop**: Video restarts automatically without interruption (use `loop` where supported)
- **No Controls**: Clean background experience without UI elements
- **Overlay Support**: Content can be placed over the video
- **Responsive**: Automatically adapts to container size

## Configuration Options

| Prop        | Value  | Purpose                     |
| ----------- | ------ | --------------------------- |
| `autoPlay`  | `true` | Start video immediately     |
| `muted`     | `true` | Permanently disable audio   |
| `loop`      | `true` | Restart video when it ends  |
| `className` | CSS    | Fill and position the video |

<Callout type="warning">
  `loop` is accepted by the React wrapper but is not currently forwarded to the Lit element. Native `<video loop>` behavior may differ by build.
</Callout>

## Best Practices

<Callout type="info">
  <strong>Browser Autoplay:</strong> The SDK handles autoplay compliance by muting the video. For background videos, keep{" "}
  <code>muted=&#123;true&#125;</code>.
</Callout>

<Callout type="warning">
  <strong>Performance:</strong> Use shorter video loops (10-30 seconds) for better performance and faster loading.
</Callout>

<Callout type="info">
  <strong>Accessibility:</strong> Provide a way for users to pause background videos if they find them distracting.
</Callout>
