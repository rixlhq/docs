Hover previews are a common UX pattern where a muted video starts playing when the user hovers over it. With the Lit-backed `Video` wrapper, you build this behavior with the standard React `onMouseEnter`/`onMouseLeave` events plus `autoPlay` and `muted`.

<Callout type="warning">
  The `theme="hover"` prop is no longer supported. The `Video` wrapper does not expose imperative `play()`/`pause()` methods, so hover
  preview is implemented by toggling `autoPlay` and `muted`.
</Callout>

## Live Example

<div className="w-full aspect-video rounded-lg overflow-hidden" onMouseEnter={() => {}} onMouseLeave={() => {}}>
  <Video id="your-video-id" className="w-full h-full object-cover" autoPlay={true} muted={true} />
</div>

## Implementation

```tsx
import {useState} from "react";
import {Video} from "@rixl/media-react";

function HoverPreview({videoId}) {
  const [isHovered, setIsHovered] = useState(false);

  return (
    <div
      className="w-full aspect-video rounded-lg overflow-hidden cursor-pointer"
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
    >
      <Video
        id={videoId}
        className="w-full h-full object-cover"
        autoPlay={isHovered}
        muted={true}
        onRixlAnalytics={(e) => console.log(e.detail.event)}
      />
    </div>
  );
}
```

## How It Works

1. Wrap the `Video` component in a `div` with hover handlers.
2. Track hover state with `useState`.
3. Pass `autoPlay={isHovered}` and keep `muted={true}` for autoplay compliance.
4. Listen to `onRixlAnalytics` to capture `content_views` events.

## Use Cases

### Product Cards

```tsx
function ProductCard({product}) {
  const [hover, setHover] = useState(false);

  return (
    <div className="rounded-lg overflow-hidden shadow" onMouseEnter={() => setHover(true)} onMouseLeave={() => setHover(false)}>
      <Video id={product.videoId} className="w-full aspect-video object-cover" autoPlay={hover} muted={true} />
      <div className="p-4">
        <h3 className="font-bold">{product.name}</h3>
        <p className="text-gray-600">{product.price}</p>
      </div>
    </div>
  );
}
```

### Video Grid

```tsx
function VideoGrid({videos}) {
  return (
    <div className="grid grid-cols-3 gap-4">
      {videos.map((video) => (
        <HoverPreview key={video.id} videoId={video.id} />
      ))}
    </div>
  );
}
```

## Best Practices

<Callout type="info">Keep `muted={true}` to satisfy browser autoplay policies.</Callout>

<Callout type="warning">
  `autoPlay` changes trigger a re-render; the video will restart from the beginning. For a smooth preview that resumes, use `analytics=
  {false}` on preview tiles and a separate detail view with a dedicated `Video`.
</Callout>
